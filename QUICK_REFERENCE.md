# 📋 Quick Reference Card - Ghana Primary School Website

## 🔐 Admin Access
- **Login URL**: `/login`
- **Default Admin**: `admin@school.com` / `password123`
- **Admin Dashboard**: `/admin`

## 📝 Common Tasks

### ➕ Adding New Content
1. **News**: Admin → News → Create New
2. **Events**: Admin → Events → Create New  
3. **Gallery**: Admin → Gallery → Create New
4. **Staff**: Admin → Staff → Create New
5. **Page Content**: Admin → Page Content → Create New
6. **Menu Items**: Admin → Menus → Create New

### 🎨 Customization Features
| Feature | Purpose | Access |
|---------|---------|--------|
| Page Content | Edit website text/images | Admin → Page Content |
| Theme & Design | Colors, fonts, custom CSS | Admin → Theme & Design |
| Menus | Header/footer navigation | Admin → Menus |
| Settings | School info, social media | Admin → Settings |

### 🖼️ Image Guidelines
| Content Type | Recommended Size | Max File Size |
|--------------|------------------|---------------|
| Hero Slides | 1920x800px | 5MB |
| News/Events | 1200x600px | 3MB |
| Gallery | 1200x800px | 3MB |
| Staff Photos | 400x400px | 1MB |
| School Logo | 200x100px | 500KB |

### 📊 Content Status
- **Published** ✅ = Live on website
- **Draft** 📝 = Saved but hidden
- **Inactive** ❌ = Hidden from public

### 🚀 Quick Actions
| Action | Steps |
|--------|-------|
| Publish News | News → Create → Fill form → Status: Published → Save |
| Add Event | Events → Create → Fill details → Set dates → Save |
| Upload Photos | Gallery → Create → Add title → Upload images → Save |
| Update Staff | Staff → Find person → Edit → Update info → Save |

### ⚙️ Settings Access
- **School Info**: Admin → Settings
- **Logo Upload**: Settings → Upload new logo
- **Contact Details**: Settings → Update information
- **Page Content**: Admin → Page Content → Manage text/images
- **Website Colors**: Admin → Theme & Design → Color scheme
- **Navigation**: Admin → Menus → Header/footer links

### 🎨 Advanced Customization
| Feature | What You Can Customize |
|---------|----------------------|
| **Page Content** | Homepage text, About page sections, Contact info |
| **Theme & Design** | Colors, fonts, custom CSS/JavaScript |
| **Menus** | Header navigation, footer links, dropdown menus |
| **Hero Slides** | Homepage slideshow images and text |
| **Core Values** | About page values with icons |

### 🔍 Finding Content
- Use the search bar in admin sections
- Filter by status (Published/Draft)
- Sort by date created or title

### 🆘 Emergency Contacts
- **Website Issues**: Contact system administrator
- **Password Reset**: Use "Forgot Password" link
- **Technical Support**: Document error with screenshot

## 📱 Mobile Admin Tips
- Admin portal works on mobile devices
- Use landscape mode for better editing
- Keep image uploads small on mobile data
- Save drafts frequently while editing
