# 🎯 New Administrator Setup Guide

## Welcome to Ghana Primary School Website!

This guide will help you get started as a website administrator in just a few simple steps.

---

## Step 1: First Login 🔐

1. **Go to the login page**: `https://your-school-domain.com/login`
2. **Use the default credentials**:
   - Email: `admin@school.com`
   - Password: `password123`
3. **Click "Login"**

## Step 2: Change Your Password ⚠️

**IMPORTANT**: Change the default password immediately!

1. After logging in, go to your profile (top-right corner)
2. Click "Profile" → "Change Password"
3. Enter a strong new password
4. Save the changes

## Step 3: Update School Information 🏫

1. **Go to Admin → Settings**
2. **Update the following**:
   - School name
   - Contact information (address, phone, email)
   - Upload school logo
   - Add social media links
   - Update mission statement

## Step 4: Create Your First Content 📝

### Add a Welcome News Article
1. Go to **Admin → News → Create New**
2. Fill in:
   - Title: "Welcome to Our New Website!"
   - Content: Brief welcome message
   - Status: Published
3. Click "Save"

### Add an Upcoming Event
1. Go to **Admin → Events → Create New**
2. Fill in:
   - Title: Next school event
   - Date and time
   - Location
   - Description
3. Click "Save"

### Upload Some Photos
1. Go to **Admin → Gallery → Create New**
2. Add a gallery title
3. Upload a few school photos
4. Click "Save"

## Step 5: Add Staff Profiles 👥

1. **Go to Admin → Staff → Create New**
2. **For each staff member add**:
   - Full name
   - Position/title
   - Department
   - Professional bio
   - Photo (optional)
3. **Set status to "Active"**
4. **Click "Save"**

## Step 6: Customize Homepage 🎨

1. **Go to Admin → Hero Slides**
2. **Create 2-3 slides with**:
   - Attractive school photos
   - Welcoming messages
   - Call-to-action buttons
3. **Set them to "Active"**

## Step 7: Create Essential Documents 📄

1. **Go to Admin → Documents**
2. **Upload important files**:
   - School handbook
   - Academic calendar
   - Admission forms
   - Parent information

## Step 8: Test Everything 🧪

1. **Visit the public website** (click "View Website" in admin)
2. **Check that everything displays correctly**:
   - Homepage slideshow
   - News articles
   - Events
   - Staff profiles
   - Gallery photos
3. **Test on mobile device**

## Step 9: Set Up Regular Maintenance 🔄

### Daily Tasks
- Check for new messages/inquiries
- Monitor website performance

### Weekly Tasks
- Add new news articles
- Update upcoming events
- Review and publish content

### Monthly Tasks
- Update staff information
- Add new gallery photos
- Review website analytics

## Step 10: Learn More 📚

- **Read the full User Manual** for detailed instructions
- **Keep the Quick Reference Card** handy for common tasks
- **Bookmark the admin dashboard** for easy access

---

## 🆘 Need Help?

### Common First-Time Issues
- **Can't log in**: Check username/password spelling
- **Images won't upload**: Make sure files are under 5MB
- **Changes not showing**: Make sure content status is "Published"

### Getting Support
1. Check the User Manual first
2. Try the troubleshooting section
3. Contact your website administrator
4. Document any errors with screenshots
